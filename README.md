# Fuxiqueiro

A local network scanner and port analyzer built with Electron, React, and TypeScript.

## Features

- Scans local network for connected devices
- Identifies device vendors and hostnames
- Scans open ports on selected devices


## Usage

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Requirements

- Node.js 16+
- Nmap (optional, for advanced scanning features if implemented)
